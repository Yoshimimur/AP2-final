# Lizenzhinweise

Für den QR-DocManager werden Slim, Tailwind CSS und Lucide verwendet.

- Slim übernimmt das Routing und die HTTP-Verarbeitung. Die Pakete Slim und Slim-PSR7 stehen unter der MIT-Lizenz.
Quelle: https://www.slimframework.com/

- Tailwind CSS wird für die Gestaltung der Oberfläche verwendet. Die Lizenz ist MIT.
Quelle: https://github.com/tailwindlabs/tailwindcss/blob/main/LICENSE

- Die Symbole stammen aus Lucide. Sie stehen unter der ISC-Lizenz. Für einige aus Feather übernommene Symbole gilt zusätzlich die MIT-Lizenz.
Quelle: https://lucide.dev/license

## Verwendete Programme

PHP, SQLite, Apache und Composer werden separat installiert und nicht als Programmdateien im Projekt mitgeliefert.

PHP: https://www.php.net/license/

SQLite: https://www.sqlite.org/copyright.html

Apache: https://www.apache.org/licenses/LICENSE-2.0

Composer: https://github.com/composer/composer/blob/main/LICENSE
